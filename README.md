# AI 에이전트 허브 플랫폼

다양한 업무 지원 AI 에이전트를 통합한 플랫폼입니다. 사용자는 크레딧을 충전하여 다양한 AI 에이전트를 활용할 수 있으며, 관리자는 플랫폼을 관리하고 회사는 직원들의 AI 에이전트 사용을 효율적으로 관리할 수 있습니다.

## 🚀 주요 기능

### 🔐 인증 및 회원관리
- **이메일 회원가입 및 로그인** - Mock 인증 시스템
- **다중 계정 시스템** 
  - 일반 사용자: 개인적 AI 에이전트 사용
  - 회사 관리자: 직원 관리 및 권한 설정
  - 회사 일반 사용자: 회사 정책 내에서 AI 에이전트 사용
  - 관리자: 플랫폼 전체 관리
- **회사 계정 특화 기능**
  - 회사 로고 관리 및 헤더 표시
  - 직원 초대 시스템
  - 부서별 권한 관리

### 💳 크레딧 시스템
- **선불 크레딧 충전 방식** - 투명한 사용량 관리
- **다양한 크레딧 패키지** (50, 100, 300, 500, 1000, 2000, 20 크레딧)
- **보너스 크레딧 제공** - 특정 패키지 구매 시 추가 혜택
- **다양한 결제 수단** (신용카드, 계좌이체, 카카오페이, 네이버페이)
- **회사 계정 크레딧 관리** - 부서별 크레딧 할당 및 사용량 추적

### 🤖 AI 에이전트 (총 10개 - 현재 7개 활성화)

#### 일반사무 (4개 중 3개 활성화)
- **회의록 자동화 AI** (10 크레딧) - 회의 내용을 체계적인 회의록으로 변환 ✅
- **이메일 작성 AI** (8 크레딧) - 목적에 맞는 전문적인 이메일 작성 ✅
- **AI PPT 슬라이드 생성기** (25 크레딧) - 전문적인 프레젠테이션 슬라이드 구성 🚧
- **음성파일 기반 문서 자동화 AI** (30 크레딧) - 음성을 다양한 문서로 변환 ✅

#### 마케팅/광고 (4개 중 3개 활성화)
- **리뷰 분석 AI** (15 크레딧) - 고객 리뷰 분석 및 인사이트 제공 ✅
- **키워드 분석 AI** (12 크레딧) - 온라인 키워드 트렌드 종합 분석 ✅
- **SNS 이벤트 기획 AI** (18 크레딧) - SNS 이벤트 전략적 기획 🚧
- **광고 문구 분석 및 제안 AI** (20 크레딧) - 광고 문구 분석 및 개선안 제안 ✅

#### 콘텐츠 제작 (2개 중 1개 활성화)
- **AI 카드뉴스 생성기** (20 크레딧) - 매력적인 카드뉴스 자동 생성 ✅
- **AI 블로그 생성기** (15 크레딧) - 고품질 블로그 포스팅 작성 🚧

### 🔍 검색 및 필터링

- **사이드바 네비게이션** - 접을 수 있는 사이드바로 효율적인 공간 활용

- **토글 기능** - 카테고리 클릭으로 필터링/전체 보기 전환

## 🚀 시작하기

### 전제 조건
- Node.js 18.17 이상
- npm 또는 yarn

### 설치 및 실행

1. 저장소 클론
```bash
git clone <repository-url>
cd angent_hub3
```

2. 의존성 설치
```bash
npm install
```

3. 개발 서버 실행 (Turbopack 사용)
```bash
npm run dev
```

4. 브라우저에서 http://localhost:3000 접속

### 빌드
```bash
npm run build
npm start
```
